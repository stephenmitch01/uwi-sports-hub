How Stats Flow Through the Platform

Stats start on the Competitions page. Users can either create a new competition first, or search for and select an existing competition. From there, the sport-specific score sheet, scorecard, or result sheet is used to enter match, event, team, and athlete data.

1. Set up the competition

Go to Competitions. If the competition does not exist yet, create it with the correct sport, season, category, round, event, fixture, or match details.

2. Select the record

Search for and open the appropriate competition before entering stats. This connects the score sheet to the correct sport and competition context.

3. Enter the score sheet

Use the sport-specific workflow to enter teams, opponents, athletes, scores, times, marks, wickets, goals, assists, attempts, placements, or other sport data.

4. Save the result

When saved, the platform links the result to the competition, sport, teams, athletes, season, and event or match details wherever those fields are provided.

5. Review propagation

The same saved data can then appear in recent results, competition detail pages, team pages, athlete stat pages, leaderboards, reports, and campus summaries.

6. Keep profiles connected

Athlete and team links matter. If a player belongs to multiple sports or teams, those assignments help the platform display the right stats in the right places.
